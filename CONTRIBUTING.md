# Contributing

Use Node 24 or later. Run `npm ci`, then `npm run check`. Changes to interactive
behavior also need `npm run test:browser` with Playwright Chromium and Firefox.

Keep the pure model separate from browser code. Preserve the distinction
between a failed premise, an unmet existence condition, an empty universe,
agreement, and a counterexample. A new logical construct needs a new
completeness argument; the eight-region bound must not be assumed for counting,
identity, relations, or modality.

Historical claims need a located passage. Inspect the complete retained page,
record edition and passage boundaries, and distinguish Greek transcription,
new translation, and modern interpretation. Do not label a modern semantic
switch as Aristotle's complete theory. Teaching Latin must stay clearly
identified as new.

When updating retained assets, inspect their actual contents and dimensions,
retain their licenses, and deliberately update both manifest copies. Do not
regenerate hashes merely to make a source check pass. Browser review must
compare the actual displayed and embedded bytes to the manifest.

Operate the complete learner journey at desktop and 375px in Chromium and
Firefox: build a counterexample, pin a comparison, read the Greek, inspect an
enlarged scan, save a notebook, and reopen its editable record. Inspect real
screenshots and printed output. Check an actual offline document reload after
worker takeover, with the origin unavailable.

Record local checks, clean-build equality, and public deployment separately.
The prepared workflows are not evidence that remote jobs have executed.
