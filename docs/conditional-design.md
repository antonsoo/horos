# A room for the disputed conditional

The learner's job is to separate a conditional's truth at one moment from a
claimed connection between its clauses. Sextus Empiricus, _Outlines of
Pyrrhonism_ II.110–114 supplies the dispute, including objections to settling it.
The existing class-membership room remains the entrance to Horos.

The new room uses a small theatre of daylight and speech. Its four possible
configurations are the working surface: select the present facts, then decide
which other cases to admit. The danger case (daylight with silence) is visible
even while another case is current. Changing the table makes an assumption,
not a discovery about what is possible. Repeated “day” clauses share one truth
value rather than being independent switches.

Palette: cloud `#eef3f6`, blue ink `#173448`, deep stage `#123b50`, chalk
`#f9fcfd`, copper `#9d352a`, muted blue `#506575`. Literata carries the
conditional and Greek; Source Sans 3 carries operations and explanations.
Reuse the retained fonts. Left-align text; use the stage's large drawing as the
one expressive element. A quiet, persistent room selector connects Aristotle
and Sextus. No decorative scoring, rewards, or pseudo-ancient interface terms.

```text
horos    Class arguments | Conditionals          Read | Keep

When is "if" true?     [the current conditional in Greek]

+---------------------------+-------------------------------+
| daylight / speech stage   | four considered cases         |
|                           | choose current / allow case   |
| change the present facts  | excluded current = conflict   |
+---------------------------+-------------------------------+
| Philo: current facts      | finite compatibility test     |
+---------------------------+-------------------------------+
| pin / compare / explain / reopen / save                  |
| Greek reading + selectable words | complete source page |
```

Review against the brief: a truth-table calculator alone would miss the point.
The four-case surface makes the additional assumptions operable, retains
inconsistent drafts, and identifies vacuous passes. The source preserves all
four reported accounts. Only Philo's criterion and a finite compatibility
analogue are computed; a finite table does not reconstruct ancient modality,
Diodorus's temporal criterion, or an account of relevance/containment.

Verification must include the same current facts under different tables,
identity constraints, empty tables, absent antecedents, inconsistent current
facts, pinning, editable records and real portable readings. The two printed
source pages, fonts and notices must be byte-checked in the reader and export.
Publication is a separate step; HOUSE_STANDARDS.md reserves it for review.
